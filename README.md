# CouponBuz

A high-performance, modern React application for verified promo codes, discount deals, and international coupon management, equipped with an instant-publishing Shopify-style hidden Admin CMS.

## Features

- **Public Coupon Platform**:
  - **Instant Search**: Real-time autocomplete suggestions for brands and coupon codes.
  - **Store Directory (A–Z)**: Browse hundreds of retailers alphabetically with active deal counters.
  - **Coupon Reveal Modal**: 1-click copy with feedback ("Copied!"), instructions, and direct store outbound links.
  - **Multi-Country Coverage**: Country-specific voucher pages for the US, UK, Canada, Australia, and European markets with localized shopping advice and currency tags.
  - **Seasonal Savings Hubs**: Dedicated landing pages for Black Friday, Cyber Week, and holiday shopping.
  - **Savings Guides Blog**: In-depth shopping advice on code stacking, cashbacks, and clearance savings.
  - **Interactive Support Bot ("Buzz")**: Instant FAQ matching, store coupon lookup, and email hand-off.
  - **Community Submissions**: Visitors can submit working coupons with instant moderation queues.

- **Instant Live Admin CMS (Hidden & Secure)**:
  - **Protected Access**: Hidden from the general public; protected by admin PIN (Default: `admin123`).
  - **Instant Live Publishing**: All changes made in the CMS reflect on the live website immediately without requiring a rebuild or redeploy.
  - **Shopify-Style Dashboard**: Sleek, intuitive catalog and content management interface.
  - **CSV Import & Export Studio**: Bulk export and import for Stores, Coupons, Categories, and Full JSON Backups.
  - **Full Website Customizer**: Edit announcement bar, home page section order and visibility, theme colors, logos, and custom `<head>` scripts.
  - **Submission Moderation**: 1-click approval of visitor-submitted coupons into live offers.

## Commands

```bash
# Start development server on port 3000
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
